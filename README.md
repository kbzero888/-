# ModernTachometer (现代数字光电转速计)

基于原生协议完全重构的现代化 USB 串口光电转速计 Android 客户端，采用 **Kotlin + Jetpack Compose + Material Design 3** 构建，并内置 **GitHub Actions** 云端自动编译流水线。

## 核心功能
- **即插即用 USB 串口驱动**：支持 CH340/CH341/CP210x/FTDI 芯片，默认 `115200 bps (8-N-1)`，插入自动请求授权连接。
- **三级设置菜单与自定义看板**：
  - **第一界面（主看板）**：超大号等宽数字实时展示 RPM，支持点击空白处或键盘回车取消输入框焦点。
  - **第二界面（设置中心）**：点击右上角齿轮图标进入，聚合「波特率修改」与「转速数据显示修改」入口。
  - **第三界面（详细配置）**：支持切换串口波特率（`9600` ~ `230400`），以及独立控制「最大值、最小值、平均值、有效采样」四项指标的显示与隐藏。
- **双模式校准系统**：支持倍率系数 $K$ 微调、反光贴/叶片数自动除频，以及忽略 `0` 转速开关。
- **完整硬件控制兼容**：100% 还原原版 11 字节上行数据帧与 8 字节下行控制帧，支持加/减计数切换、硬件计数清零及 `m/s` / `km/h` 线速度实时换算。
