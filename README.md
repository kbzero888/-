# ModernTachometer (现代数字光电转速计)

基于原生协议完全重构的现代化 USB 串口光电转速计 Android 客户端，采用 **Kotlin + Jetpack Compose + Material Design 3** 构建，并内置 **GitHub Actions** 云端自动编译流水线。

## 核心功能
- **即插即用 USB 串口驱动**：支持 CH340/CH341/CP210x/FTDI 芯片，默认 `115200 bps (8-N-1)`，插入自动请求授权连接。
- **核心转速与极值看板**：大号等宽字体实时展示 RPM，同步统计并显示**最大值、最小值、平均值**及有效采样次数。
- **双模式校准系统**：
  - **倍率系数 $K$**：支持任意小数倍率微调。
  - **反光贴/叶片数自动除频**：转轴贴 $N$ 片反光贴时直接选择对应数量，自动换算真实转速。
  - **零值过滤开关**：自动忽略停转时的 `0` 转速数据，避免拉低平均值与最小值。
- **完整硬件控制兼容**：100% 还原原版 11 字节上行数据帧与 8 字节下行控制帧，支持**加/减计数切换**、**硬件计数清零**及 **线速度 (`m/s` / `km/h`) 实时换算**。

## 云端自动编译 (GitHub Actions)
将本项目文件推送至 GitHub 仓库的 `main` 或 `master` 分支后，打开仓库顶部的 **Actions** 标签页，等待 `Build Android APK` 工作流运行完毕，即可在底部 **Artifacts** 中直接下载已签名的 `ModernTachometer-Debug-APK`。
